PART 2 — Global policies
Architecture invariant: CLI/REPL → Application → {Providers, Config, Validators} → Engine. Engine never imports app code; providers/config/validators never import the engine (providers re-declare the LLMClient shape locally as a Protocol). Enforced by a layer-isolation test, not convention.
Engine-freeze policy: frozen by default. Permitted exception class: additive, default-preserving seams with dedicated regression tests. Five authorized seams:
#	Seam	Semantics
S1	run_pipeline(..., validators: tuple[str,...] | None = None)	None = current behavior; ("epubcheck",) = internal+EPUBCheck; () = internal only
S2	run_pipeline(..., event_cb=None)	PipelineEvent schema; engine wraps callback in try/except — UI bugs never kill conversions
S3	CancellationToken	checked between pages, Tier-2 batches, repair attempts
S4	Phase 0.5 repair patch	correctness fix, specced there
S5	run_pipeline(..., precomputed_reports=None)	provided = skip Phase-3 routing, reuse preflight (feeds vision-bypass ratio + Tier-2 batching unchanged)
@dataclass(frozen=True)
class PipelineEvent:
    type: str  # phase_started | page_progress | tier2_batch_started
               # | validation_started | repair_started | completed | failed
    phase: int
    page_index: int | None
    total_pages: int | None
    message: str
    metadata: dict
Cancellation flows through the token only. CLI/REPL translates KeyboardInterrupt → token cancel → clean result, session intact.
Risk model: engine-adjacent phases = engine-low-risk; application layer = application-medium-risk (new user-visible behavior lives there regardless).
Baseline discipline: record reality — python --version, pytest --version, pytest --collect-only -q, Measure-Command { pytest }, passed/skipped/failed, EPUBCheck/Ace availability. Skips stay skips.
Gate philosophy: full suite after every phase. If an old engine test fails because an app feature was added, the app change is wrong — full stop.

Phase 0.5 — Online self-repair: characterize, then fix

Characterization tests (pin first): digest repair receives non-empty digest; vision repair receives its raster; route type survives release; empty/parse-failed repair output → original elements kept + warning; only failing-chapter pages ∩ Tier-2 pages are re-prompted; order stable; terminates at max_repair_attempts; offline repair unchanged; rebuilt payloads released after repair; repair responses bypass the conversion cache (pinned as deliberate — repair prompts carry validator context).
Fix (seam S4): _repair_stream(..., doc=doc) (or rebuilder callback) — rebuild via attach_payload, release after; Tier2Request.vision: bool | None = None explicit flag; empty/failed-replacement guard (keep originals); re-prompt scoped via ChapterRecord.page_nums.
Outcome: repair can only improve or preserve pages; spend scoped to actual failures.
Gate: full suite + new regression tests green.
Phase 0.7 — Targeted engine hardening (audit findings)
Goal: close the audit's one confirmed correctness hole + three cheap verified hardening items. Same rule as 0.5: additive, regression-tested, freeze-exception for correctness only.
Item 1 — Router columnar co-occurrence signal (correctness; FN≈0 is the router's design goal).
Problem: count_order_violations needs a backward-Y jump (dy < -20pt). Row-interleaved two-column emission (left-1, right-1, left-2, right-2…) is monotone in Y → zero violations → score 100 → Tier 1 → y-then-x sort reproduces the interleaving → scrambled prose. Block-ordered columns are already caught (test_two_column_jump_is_counted); interleaved emission has no fixture and no test.
Work: add a signal to confidence_router that counts line pairs with overlapping y-intervals, disjoint x-intervals, and separation above a page-width-relative gutter scale (the digest fallback's normalized-spread logic — TWO_COLUMN_SPREAD_FRACTION = 0.18 — is the reference implementation to crib from); count above a calibrated floor ⇒ penalty pushing below TIER1_THRESHOLD. Extend make_fixtures.py with an interleaved-emission two-column page. Add a code comment documenting decision #17 (why ORDER_JUMP_DX is untouched).
Edge cases the tests must prove: interleaved two-column page → tier2; block-ordered two-column → still tier2 (existing tests green); clean single-column full pages → still tier1; wide centered title page → tier1 (a title shares no baseline with a body line); single wide indented blockquote or code line → tier1; page with figure + caption → unaffected; furniture band exclusion respected (folios don't fire it); calibration constants grouped at module top.
Outcome: no known text-layer emission pattern for multi-column pages can reach Tier 1.
Item 2 — Pre-insertion well-formedness gate (defense-in-depth).
Problem: build_epub_publication passes the joined chapter body to EpubHtml.set_content with no local check; ebooklib swallows parse errors → empty chapter (the project's own documented war story), and an empty chapter is still well-formed XML — so internal validation can't catch the loss. Today's paths sanitize upstream; the insertion point itself is unguarded against any future leak.
Work: before set_content: well-formedness-check the assembled body → on failure run it through sanitize_and_validate_xhtml, recheck → still bad or empty despite non-empty input elements → raise (a loud failure the repair loop can route), never swallow.
Tests: deliberately malformed StreamElement constructed directly (bypassing the sanitizer) → packaging raises/flags, nothing silently emptied; sanitizer-recoverable body → recovered content present in output EPUB; test_chapter_content_is_not_silently_dropped and valid-build tests stay green.
Item 3 — indent_chars dead code removal.
Grep-proven: declared (332), written (492), carried (652), read nowhere. The 0.6×size char-width heuristic is monospace-flavored and wrong for proportional text — harmless only because unused. Remove field + computation + carry; add a comment at _collect_code_blocks noting its own 0.6×size use is valid because it only sees monospace pre lines. Allowed mechanical test edit: constructor-signature sync only, if any test builds ClassifiedLine directly — no behavior changes.
Gate within item: full suite byte-green.
Item 4 — table overflow hardening.
Tier-2 <table> passthrough renders against width:100% with no overflow mitigation → horizontal clipping on narrow readers. Wrap table blocks at render time in <div class="tbl">; add .tbl { overflow-x: auto; } to DEFAULT_CSS (keep existing widths). Degrades gracefully where overflow-x is unsupported (behavior = today; old Kindle ignores it — acceptable progressive enhancement).
Test: a table BLOCK element renders with the wrapper; wrapper + rule present in output EPUB.
Outcome: the audit's real findings are closed; its two misdiagnosed "fixes" (threshold drop, Tier-1 column sorting) are explicitly rejected with documented reasons.
Gate: full suite + ~8–10 new tests green.

Phase 5 — Credential resolver

Provider-specific always beats generic — silently shipping a generic key to an arbitrary OpenAI-compatible endpoint is a leak.

Phase 7 — ConversionRequest / ConversionOptions + two-level validation
@dataclass(frozen=True)
class ConversionRequest:
    pdf_path: Path
    output_path: Path
    title: str | None = None        # None → PDF metadata → engine default
    author: str | None = None       # (keeps the metadata-fallback tests honest)
    provider_id: str = "none"
    conversion_model: str | None = None
    options: ConversionOptions = ConversionOptions()

@dataclass(frozen=True)
class ConversionOptions:
    batch_size: int = 4
    cache_dir: str | None = None
    max_repair_attempts: int = 2
    skip_validation: bool = False
    report_only: bool = False
    font_sample_pages: int = 160
    spool_images: bool = True
    quiet: bool = False
L1 request validation (never opens the PDF): path exists & is file; output policy (not-a-dir, parent creatable, explicit overwrite/--force semantics — never claims writability it can't prove); provider exists; model-in-catalog only when provider_id != "none"; scalar bounds. Fails before any conversion work.
L2 document preflight (online only): open PDF → route_document(doc, build_payloads=False) → derive requirement set: tier2_digest > 0 ⇒ DIGEST; vision pages that will actually reach the model (NOT bypassed: offline ⇒ bypassed; online ⇒ bypassed only when vision_ratio < 0.10 and not CMap-corrupted) ⇒ VISION → check selected model before spend; yields cost advisory (Tier-2 counts).
Memory contract (pinned): preflight holds zero payload bytes. Suite already pins triage laziness (test_payloads_are_lazy_by_default, test_triage_of_a_long_document_holds_no_payloads); add one app-level assertion that all preflight reports have raster_bytes is None and layout_digest is None.
Tests/edge cases: every L1 failure; offline + model=None accepted; named provider + missing credential → CredentialError; digest-only doc + text-only model → allowed; vision doc + text-only model → clear pre-spend rejection; title=None + metadata-bearing PDF → engine fallback via existing tests.
Gate: tests/application/test_request.py; full suite.
